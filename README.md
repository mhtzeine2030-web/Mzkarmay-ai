# MZKarmay AI — MVP starter

واجهة أولية لمنصة عربية/إنجليزية لإنشاء المواقع والتطبيقات بالذكاء الاصطناعي.

## التشغيل محلياً
1. ثبّت Node.js (الإصدار 20 أو أحدث).
2. فك ضغط المشروع.
3. افتح الطرفية داخل مجلد المشروع وشغّل:
   ```bash
   npm install
   npm run dev
   ```
4. افتح الرابط المحلي الذي يظهر في الطرفية.

## ما الذي يعمل الآن؟
- واجهة رئيسية متجاوبة بالعربية والإنجليزية.
- مربع وصف الفكرة وقوالب جاهزة تملأ الوصف.
- تبديل بين تبويب المعاينة والكود (واجهات أولية).
- نموذج تفاعلي يلتقط الوصف ويعرض تنبيهاً.

## ما الذي لم يُربط بعد؟
هذه نسخة واجهة أولية وليست بديلاً مكتملًا عن Bolt.new. يلزم بناء وربط:
- خادم آمن وواجهة API لنموذج ذكاء اصطناعي.
- توليد ملفات المشروع فعلياً وتشغيلها داخل بيئة معزولة.
- محرر أكواد ومعاينة حقيقية.
- تسجيل دخول وقاعدة بيانات وحفظ المشاريع.
- نشر المواقع وتصدير تطبيقات Android/iOS (مثل مسار React Native/Expo)، مع إعدادات المتاجر والتوقيع.

لا تضع مفاتيح API داخل كود المتصفح؛ خزّنها في الخادم أو متغيرات البيئة.
